# Glosario

| Término | Significado |
| --- | --- |
| Organización | El tenant: estudio o entrenador que contrata la plataforma. |
| Owner | Dueño de la organización. Único que administra equipo, configuración y facturación. |
| Colaborador | Staff invitado, con un subconjunto de permisos. |
| Cliente | El alumno. Puede existir sin usuario hasta que acepta la invitación. |
| Bono | Pack de créditos que habilita reservas. |
| Crédito | Unidad que se descuenta al reservar y puede volver si la cancelación es a tiempo. |
| Ledger | Historial de solo inserción. El saldo es la suma de los deltas. |
| Ocurrencia | Una fecha concreta de una serie o de un turno. |
| Serie | Regla de recurrencia. No es cada clase suelta. |
| Rutina de biblioteca | Plantilla reutilizable. |
| Rutina de cliente | Copia creada al asignar. El historial del alumno no cambia si se edita la biblioteca. |
| Tarea personalizada | Tarea de un programa asignado que el profesional editó para ese cliente. La propagación no la pisa. |
| Sync id | Identificador de cliente para un registro creado sin conexión. El servidor hace upsert por ese id. |
| PAR-Q | Cuestionario de aptitud física previo al entrenamiento. Dato de salud. |
| 1RM | Una repetición máxima. En el producto se estima con la fórmula de Epley. |
| RPE / RIR | Esfuerzo percibido y repeticiones en reserva. |
