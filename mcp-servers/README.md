# MCP servers

Servers locales para Cursor: PostgreSQL, Azure DevOps (13 tools + 3 extensiones) y Notion (las mismas 16 tools).

```bash
cd mcp-servers
yarn install
```

Copiar `.mcp.json.example` (raiz del repo) a `.cursor/mcp.json` y completar placeholders.
No commitear `.cursor/mcp.json` (contiene secretos).
